# Deep learning for SLR prediction

## Intro
This repo builds upon work based on the paper titled "Snow-to-liquid ratio prediction over the contiguous United States using machine learning", _in review_.

## About
Using daily CoCoRaHS snowfall observations and ERA5 reanalysis, and trained, validated, and tested a convolutional neural network (CNN) and a vision transformer (ViT) to predict snow-to-liquid ratio (SLR) across the contiguous United States (CONUS). 
These deep learning models were developed to attempt to improve predictions for relatively low (<= 7.5) and high (>= 20) SLRs, which the RF struggled to forecast in the above paper in review.

Funding for this research was provided by the NOAA Weather Program Office.
